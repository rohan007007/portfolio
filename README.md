## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18, GSAP (ScrollTrigger & Timeline animations), Lenis Smooth Scroll, Framer Motion, Lucide Icons, Tailwind CSS, CRACO.
- **Design Language**: High-contrast dark editorial aesthetic (`#0a0a0a` / `#141416`), acid-yellow (`#d9ff3f`) signature accents, dual-typeface typography (Cormorant Garamond serif + Syne display sans).
- **Deployment**: Automated CI/CD deployment via GitHub Actions (`.github/workflows/deploy.yml`) directly to **GitHub Pages**.

## 🚀 Local Development

To run this project locally:

```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>/frontend

# Install dependencies
yarn install

# Start development server
yarn start
```

Runs on [http://localhost:3000](http://localhost:3000).

---

## 📦 Production Build

```bash
cd frontend
yarn build
```

Build outputs are generated in `frontend/build/` with relative asset links (`homepage: "."`), ready for static hosting anywhere.
